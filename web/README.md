# web

The Rotation app (Next.js 16 + Supabase Auth): cycle clock, my plan, my stack, Basket Lab.

```sh
npm install
npm run dev          # needs .env.local: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
```

`lib/cycle-rules.json`, `lib/coins.json` and `public/explorer.html` are generated by the engine:
`cd ../engine && uv run rotation web-data`. Don't edit them by hand.
